# 文档编译器契约（两端共用，冻结后不得随意改）

## 输入：日志层条目

```json
{
  "ts": "2026-10-11T08:31:02+08:00",
  "text": "嗯，我觉得这个方案可以，吧",
  "audio": "recordings/2026-10-11/083102.wav",
  "dur_ms": 4200
}
```

- `text` 为原始转写（含语气词），永不修改。
- 跨零点的条目按 `ts` 日期归属。

## 输出：每日文档

路径：`docs/daily/YYYY-MM-DD.md`

```markdown
# 2026-10-11

## 08:30
我觉得这个方案可以。

## 14:05
...
```

## 规则

1. 清洗发生在分句完成后，需句子级上下文。
2. 语气词：删句首"嗯/呃/那个"及重复堆叠；留句尾语气"吧/呢/啊"、
   感叹"啊"、问答应答"嗯"。规则先行，歧义项小模型判别。
3. 不在 ASR 解码阶段压制语气词（保护时间戳对齐）。
4. 幂等：重跑不重复、不丢失；人工修订过的段落不再覆盖。
5. 修订闭环：用户在文档中的手动修改要能回流为规则/词库。
